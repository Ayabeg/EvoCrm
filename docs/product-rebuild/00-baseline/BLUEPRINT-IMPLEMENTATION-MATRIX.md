## 0. Product philosophy (do not skip)

EvoCRM already has the pieces (DataWorkspace, DataGrid, FilterBuilder, SavedViews, RecordWorkspace, QuickRecord, Pipeline, Inbox). It does not have one frame. The rebuild is **one shell, one header, one scroll rule, one density scale, four archetypes**. It is not a rewrite of Inertia props, policies, routes, server filters, or component APIs.

Kept from the 30 Sep approval: light workspace, orange only for the one primary, teal for selection, one sidebar for all modes. Dropped: the dark 212px slab and the global top bar.

**Protected (do not touch):** Inertia page contracts and props, permissions/policies, routes and URLs, server-side filtering / sorting / pagination, saved views, DataWorkspace / DataGrid / FilterBuilder / SavedViews / RecordWorkspace slots / QuickRecordPeek / Pipeline + DnD announcements / LostReasonDialog / Inbox real-time hooks / Outbound / Automation / Agents / EvoViz / cmdk / PR1 tokens / `format.ts` / Simple Mode as implemented in `app/Support/SimpleMode.php`.
