## Linear

Cited: [issue list](https://mobbin.com/screens/9ec39891-cdbb-4d57-b0c6-de43f82c5f4e), [grouped list + display menu](https://mobbin.com/screens/94bb4d3b-a8e3-41e8-b8f1-b82d1f904b03), [command-adjacent empty search](https://mobbin.com/screens/dba91946-d147-4b2f-ad92-4195eae017fc)

| | |
|---|---|
| **Pattern** | Continuous workspace. Rows, not cards. Views as quiet tabs. Display controls in a popover. Command is the search. |
| **Why it works** | Density without microscopic type. Hierarchy is typography and grouping, not boxes. |
| **EvoCRM adaptation** | List pages should feel this calm: table as the page, filter band as hairline chrome. Command OS stays the global search. |
| **What not to copy** | Issue-tracker IA, status dots as decoration, purple product identity, “try Linear” empty marketing. |

## Stripe

Cited: [settings index](https://mobbin.com/screens/61d8519b-582c-4749-a1df-1ff712e3a810), [billing setup list](https://mobbin.com/screens/0f4ab008-c3d5-46cd-9e88-4e788a240607), [record-like detail](https://mobbin.com/screens/f8db8469-2830-4c6b-98ca-53bf4c1e3caf)

| | |
|---|---|
| **Pattern** | Settings as a directory of destinations, then a single form column. Detail pages use definition lists, not card grids. |
| **Why it works** | Operators find a place, then stay in one measure. No marketplace noise. |
| **EvoCRM adaptation** | Keep P21 grouped nav. Settings pages stay max ~900. Use Stripe’s directory calm for the settings landing, not for CRM lists. |
| **What not to copy** | Purple accent, preview panes that turn settings into a marketing site, copy voice. |

## Shopify

Cited: [products table](https://mobbin.com/screens/5f122fb7-7cef-4372-97c1-b9598df21c3d), [orders + filter chips](https://mobbin.com/screens/9a5dbafc-fc4a-4bfb-9ae4-98b1a61ed95d)

| | |
|---|---|
| **Pattern** | One white table surface on a gray app canvas. Filters sit on the table, not in a second card. KPI strip can live above without boxing each metric. |
| **Why it works** | The table is the product. Filters feel attached to data. |
| **EvoCRM adaptation** | DataWorkspace should land as one surface (Shopify) not a stack of bordered bands (current). KPI-above-list is for Home/Orders, not every CRM object. |
| **What not to copy** | Green identity, admin IA, “Learn more about products” marketing slots. |

## HubSpot

Cited: [contacts list](https://mobbin.com/screens/2c2951a8-ec56-41c0-a3e0-990330bdc5f4), [saved views menu](https://mobbin.com/screens/2c484062-a046-46b3-b494-0d12c00b2ac3), [advanced filters drawer](https://mobbin.com/screens/edbed4a5-0814-4c04-bf4e-c55dc948a900), [filter editor](https://mobbin.com/screens/6005f6c6-9c5e-4350-8884-fc0bf3e90c01)

| | |
|---|---|
| **Pattern** | Saved views + chips + advanced drawer + wide table. Filters do not take the page. |
| **Why it works** | This is the CRM list grammar operators already know. EvoCRM DataWorkspace already implemented the behavior. |
| **EvoCRM adaptation** | Keep the grammar. Drop HubSpot’s teal header, orange-on-teal CTAs, and the extra “Data quality / Import” junk drawer. Views stay pills, not a giant index modal unless the list of views grows past ~8. |
| **What not to copy** | Teal identity, Copilot chrome, HubSpot orange-on-teal buttons, property encyclopedia density in the filter picker. |

## Attio

Cited: [company record + activity](https://mobbin.com/screens/297adfeb-8312-496b-8acf-41839a6cf775), [record details rail](https://mobbin.com/screens/3f58982f-fb3f-46de-a123-70350ebfa604), [emails + details](https://mobbin.com/screens/2b32899d-6868-4595-a3b9-4d9eb8fe7642)

| | |
|---|---|
| **Pattern** | Record as activity + details. Properties are a definition list. Almost no cards. Attributes edit inline. |
| **Why it works** | High density without noise. The record feels like one document. |
| **EvoCRM adaptation** | Record 3-pane should flatten toward Attio’s details rail (label / value, not boxed groups). Keep EvoCRM’s About / Activity / Insights split — do not go single-canvas Attio IA. |
| **What not to copy** | Minimal black brand, list-as-spreadsheet-only IA, attribute model. |

## Pipedrive

Cited: [pipeline board](https://mobbin.com/screens/fa0efe82-ea90-4864-ae99-ca3dd822c77b), [stage editor](https://mobbin.com/screens/61a6aa88-05df-4863-92f7-66dce180a193), [won/lost dock](https://mobbin.com/screens/bb14ee04-5a09-488b-9b92-ab95e36860e0)

| | |
|---|---|
| **Pattern** | Board is the page. Slim top tools. Columns carry amount + count. Cards are small. Won/lost as a dock, not a sixth decorative column. |
| **Why it works** | Pipeline reading distance. Empty columns stay empty, not boxed. |
| **EvoCRM adaptation** | Board-first signature. Keep EvoCRM stage contract (`New → Qualified → Demo → Proposal → Won → Lost`). Forecast as numbers, not a Pipedrive promo banner. |
| **What not to copy** | Green empty illustrations, AI chat entry in the header, deal probability chrome, navy rail. |

## Intercom (and adjacent desk)

Cited: [Intercom inbox 4-pane](https://mobbin.com/screens/b1a806f1-b212-45a8-b525-fea3fa01b961), [Front thread](https://mobbin.com/screens/ae318c5b-e407-4061-8472-290183d2e3de)

| | |
|---|---|
| **Pattern** | Folders, list, conversation, customer details. Conversation is the widest column. Details are a property rail. |
| **Why it works** | The operator’s eye stays on the thread. Context is available without becoming a fourth card stack. |
| **EvoCRM adaptation** | Native inbox already aims here. Slim the CRM context pane. Do not add Intercom’s Copilot column as a default. |
| **What not to copy** | Intercom purple, Copilot as a first-class fourth column, Front’s tag-editing chrome. |

## Salesforce

Cited: [lead workspace + path](https://mobbin.com/screens/bfca53c8-202b-48aa-954d-cb58efa99231), [3-column activity](https://mobbin.com/screens/68810f1d-68e6-4a93-9257-1f654ad00356), [contact workspace](https://mobbin.com/screens/2a226499-35fc-42aa-a5c8-49e0fed76557)

| | |
|---|---|
| **Pattern** | Path + 3 columns (about, activity, related). Highlights and related lists on the right. Global search in the top bar. |
| **Why it works** | Workflow depth: you can work a record without leaving it. |
| **EvoCRM adaptation** | Keep 3-pane RecordShell. Do not adopt Lightning path chrome, utility bar, or related-list card pile. Path for deals stays the existing stage control, not a Salesforce path widget. |
| **What not to copy** | Blue identity, path control styling, Slack-in-the-record marketing, stacked related-list cards, tab overflow. |

## Cross-pattern (what EvoCRM takes)

| Need | Take from | Express as |
|---|---|---|
| List calm | Linear + Shopify | Continuous table surface |
| List grammar | HubSpot | Views + chips + advanced drawer (already built) |
| Board reading | Pipedrive | Board-first, quiet cards |
| Record depth | Salesforce structure + Attio flattening | 3-pane, definition lists |
| Inbox | Intercom structure | Desk columns, slim context |
| Settings | Stripe | Directory + one form column |
| Command | Linear | One palette, 36px rows |

Nothing above authorizes a visual clone.
